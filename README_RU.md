# Семейный бюджет — Android-приложение

Автономное приложение для учёта семейных финансов (Kotlin + Jetpack Compose + Room).
Повторяет логику вашей Google-таблицы «16 Бюджет» и работает без интернета. Отправка операций в таблицу — по желанию.

## Что умеет

**Обзор**
- Текущий баланс по всем счетам.
- Выбор месяца: остаток на начало и конец, доходы, расходы, обязательные платежи, разница.
- «Бюджет месяца»: сколько потрачено от суммы лимитов.
- Обязательные платежи с галочками. Галочка сама создаёт расход, снятие галочки его удаляет.
- Остатки по каждому счёту.

**Операции**
- Журнал по месяцам, сгруппирован по дням, с суммой за день.
- Фильтр: все / расходы / доходы / переводы, поиск по категории, комментарию и человеку.
- Добавление, редактирование и удаление. Переводы между своими счетами.

**Отчёты**
- Кольцевая диаграмма расходов или доходов по категориям: сумма, число операций, доля.
- Столбчатый график расходов по дням, самый затратный день.
- Лимиты по категориям: потрачено, осталось, превышение. Жёлтый цвет с 80%, красный при превышении.

**Год**
- Доходы, расходы, накопления и среднемесячные расходы за год.
- Графики трат и доходов по месяцам, таблица с накоплениями нарастающим итогом.
- ТОП-15 категорий расходов.

**Ещё**
- Категории и лимиты (стартовые взяты из вашей таблицы), обязательные платежи, счета с начальным остатком, люди (Я, Аня и т.д.), валюта.
- Экспорт всех операций в CSV (открывается в Excel).
- Синхронизация с Google-таблицей.
- Тёмная тема подхватывается автоматически.

## Что улучшено по сравнению со стартовым проектом

- Локальная база Room: данные не пропадают и работают офлайн. Раньше запись шла только онлайн.
- URL и токен вводятся в приложении (Ещё → Google Таблица). Пересобирать APK ради них не нужно, секреты не лежат в исходниках.
- Очередь отправки: операции помечаются «не отправлено» и уходят одной кнопкой или автоматически. Повторная отправка не создаёт дубль, потому что у каждой операции постоянный `uid`, который скрипт использует как `requestId`.
- В таблицу уходит реальная дата операции, а не момент отправки. Скрипт обновлён (v0.3.0).
- Справочники категорий, счетов и людей настраиваются в приложении, а не вводятся вручную каждый раз.
- Иконка приложения, поддержка edge-to-edge и тёмной темы.

## Сборка APK без компьютера (GitHub Actions)

1. На github.com создайте приватный репозиторий.
2. Загрузите в него **содержимое** папки проекта (не ZIP). В корне должны быть `app`, `scripts`, `.github`, `build.gradle.kts`, `settings.gradle.kts`, `gradle.properties`.
3. Вкладка **Actions** → **Собрать Android APK** → **Run workflow**.
4. Когда появится зелёная галочка, откройте запуск и скачайте артефакт `family-budget-debug-apk`. Внутри `app-debug.apk`.
5. Установите APK, разрешив установку из неизвестных источников для браузера или файлового менеджера.

Через Android Studio: откройте папку проекта (JDK 17, Android SDK 35), дождитесь Gradle Sync, затем Build → Build APK(s).

## Подключение Google-таблицы (необязательно)

Нужна таблица с листом `Операции`, колонки A:I:
дата, сумма, тип, категория, комментарий, способ оплаты, кто, счёт отправителя, счёт получателя.

1. В таблице: Расширения → Apps Script, вставьте содержимое `scripts/Code.gs`.
2. Замените `REPLACE_WITH_A_LONG_RANDOM_SECRET_AT_LEAST_32_CHARS` на случайный секрет не короче 32 символов.
3. Развёртывание → Новое развёртывание → Веб-приложение. Выполнять от своего имени, доступ: «Все» (защита идёт токеном).
4. Скопируйте URL веб-приложения.
5. В приложении: Ещё → Google Таблица. Вставьте URL и тот же токен, нажмите «Сохранить», затем «Проверить».

Названия типов в таблице: `Доход`, `Расход`, `Перевод`. Если скрипт создан не из самой таблицы, впишите её ID в `SPREADSHEET_ID`.

## Ограничения

- Изменения и удаления уже отправленных операций в таблице не обновляются, отправка идёт только в одну сторону (приложение → таблица).
- Токен хранится на устройстве в обычных настройках приложения. Не публикуйте URL, токен и APK.
- Это debug-сборка, не релиз для магазина. Резервной копии базы нет, кроме экспорта в CSV и штатного резервного копирования Android.
- Код написан без возможности запустить сборку в среде автора. Первая компиляция происходит в вашем GitHub Actions. Если сборка упадёт, пришлите лог ошибки, это обычно правится парой строк.

## Структура

```
app/src/main/java/ru/familybudget/app/
  MainActivity.kt        навигация (нижняя панель) и редактор операции
  BudgetViewModel.kt     состояние, действия, экспорт, синхронизация
  data/                  Room (операции, категории, счета, платежи), настройки, отправка в таблицу
  logic/                 расчёты (остатки, категории, месяцы, год), форматирование
  ui/                    экраны: Обзор, Операции, Отчёты, Год, Настройки; диаграммы и общие компоненты
scripts/Code.gs          Google Apps Script
.github/workflows/       облачная сборка APK
```
