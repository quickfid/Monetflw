# Семейный бюджет — Android-приложение

Автономное приложение для учёта семейных финансов (Kotlin + Jetpack Compose + Room).
Повторяет логику вашей Google-таблицы «16 Бюджет» и работает без интернета. Отправка операций в таблицу — по желанию.

## Что умеет

**Обзор**
- Текущий баланс по всем счетам.
- Выбор месяца: остаток на начало и конец, доходы, расходы, обязательные платежи, разница.
- «Бюджет месяца»: сколько потрачено от суммы лимитов.
- Обязательные платежи с галочками. Галочка сама создаёт расход, снятие галочки его удаляет.
- Остатки по каждому счёту.

**Операции**
- Журнал по месяцам, сгруппирован по дням, с суммой за день.
- Фильтр: все / расходы / доходы / переводы, поиск по категории, комментарию и человеку.
- Добавление, редактирование и удаление. Переводы между своими счетами.

**Отчёты**
- Кольцевая диаграмма расходов или доходов по категориям: сумма, число операций, доля.
- Столбчатый график расходов по дням, самый затратный день.
- Лимиты по категориям: потрачено, осталось, превышение. Жёлтый цвет с 80%, красный при превышении.

**Год**
- Доходы, расходы, накопления и среднемесячные расходы за год.
- Графики трат и доходов по месяцам, таблица с накоплениями нарастающим итогом.
- ТОП-15 категорий расходов.

**Ещё**
- Категории и лимиты (стартовые взяты из вашей таблицы), обязательные платежи, счета с начальным остатком, люди (Я, Аня и т.д.), валюта.
- Экспорт всех операций в CSV (открывается в Excel).
- Синхронизация с Google-таблицей.
- Тёмная тема подхватывается автоматически.

## Что нового в версии 1.3

- **Фиксированные платежи.** Аренда, кредит, связь и коммунальные теперь считаются фиксированными на месяц: прогноз не умножает их по дням, а берёт сумму из плана (или факт, если он больше). Раньше разовая оплата аренды на 5-й день ошибочно «растягивалась» на весь месяц.
- **Каждый месяц новые цифры.** При первом запуске в новом месяце приложение спрашивает суммы этих четырёх платежей (подставлены прошлые, нужно только поправить). Можно нажать «Позже» и изменить их на вкладке «План».
- **Вклады и накопительные счета.** Ещё → «Вклады и накопления»: название, тип, сумма, процент (в год или в месяц), галочка «проценты прибавляются к сумме». Проценты начисляются автоматически за каждый завершённый месяц и прибавляются к общему балансу («Всего с накоплениями» на главной).
- **Исправление неверных сумм.** Сумму вклада можно переписать на реальную. Проценты за любой месяц можно поправить вручную (отметка ✍️), а кнопка «Пересчитать» пересчитает остальные.
- Вклады и проценты попадают в резервную копию и в отчёт в Google Таблице (новый блок «🐷 Вклады и накопления»).
- База обновляется сама (версия 3): данные сохраняются.

## Красивый отчёт в Google Таблице

Приложение отправляет данные месяца, а скрипт строит в вашей таблице три листа:

- **📊 ГГГГ-ММ**: плитки (доходы, расходы, остаток, накоплено, прогноз, план), таблица «план и факт» с полосами выполнения и статусами ✅ ⚠️ 🔥, графики: кольцевая диаграмма расходов, план против факта, траты нарастающим итогом и расходы по дням.
- **🧾 ГГГГ-ММ**: все операции месяца с фильтром, цветными суммами и закреплённой шапкой.
- **📅 ГГГГ**: итоги года по месяцам, накопления и ТОП категорий с графиками.

После выгрузки приложение даёт ссылку: «Открыть» и «Поделиться». Чтобы другой человек увидел отчёт, откройте таблицу в Google и нажмите «Настройки доступа» (просмотр по ссылке). Листы с тем же месяцем при повторной выгрузке перезаписываются.

**Важно:** вставьте в Apps Script новую версию `scripts/Code.gs` (0.5.0) и сделайте **новое развёртывание** (Развёртывание → Управление → Изменить → Новая версия), иначе кнопка «В таблицу» покажет, что скрипт старый. Токен и URL остаются прежними. Лист «Операции» для самого отчёта не нужен, но для обычной синхронизации он по-прежнему требуется.

## Дизайн

Светлая тема повторяет вашу таблицу: бежевые заголовки с рамкой, зелёная плитка доходов, красная плитка расходов, жёлтая плитка обязательных платежей, бирюзовый акцент. Тёмная тема переделана: графитово-синий фон, мягкие бирюзовые акценты, приглушённые зелёный и коралловый вместо коричневых оттенков.

## Сборка APK для проверки (без компьютера)

1. На github.com создайте **приватный** репозиторий.
2. Загрузите **содержимое** папки проекта (не ZIP). В корне должны быть `app`, `scripts`, `docs`, `store`, `.github`, `build.gradle.kts`, `settings.gradle.kts`, `gradle.properties`.
3. Вкладка **Actions** → **Собрать Android APK** → **Run workflow**. Скачайте `app-debug.apk` из артефактов и установите.

Через Android Studio: откройте папку проекта (JDK 17, Android SDK 35), дождитесь Gradle Sync, затем Build → Build APK(s).

**Сначала проверьте debug-APK на телефоне**, и только потом выпускайте релиз.

## Публикация в Google Play: пошагово

### 1. Ключ подписи (один раз)
1. Actions → **1. Создать ключ подписи (один раз)** → Run workflow.
2. Скачайте артефакт `keystore-СОХРАНИТЕ-И-УДАЛИТЕ`. Внутри `upload.jks`, `KEYSTORE_BASE64.txt`, `PASSWORDS.txt`.
3. **Сохраните `upload.jks` и пароли в надёжном месте вне GitHub** (менеджер паролей, облако). Затем удалите артефакт. Репозиторий должен быть приватным.
4. Settings → Secrets and variables → Actions → New repository secret. Создайте четыре секрета:
   - `KEYSTORE_BASE64`: содержимое `KEYSTORE_BASE64.txt`
   - `KEYSTORE_PASSWORD` и `KEY_PASSWORD`: значения из `PASSWORDS.txt` (они одинаковые)
   - `KEY_ALIAS`: `upload`

### 2. Сборка релиза
Actions → **2. Релиз для магазина (AAB + APK)** → Run workflow. Скачайте `family-budget-release-aab`: это файл `.aab` для загрузки в Google Play. Номер версии (`versionCode`) растёт автоматически с каждым запуском.

### 3. Политика конфиденциальности
Google Play требует ссылку. Откройте `docs/privacy-policy.html`, замените `[ваш e-mail]` и `[your e-mail]` на свой адрес. Затем в репозитории: Settings → Pages → Deploy from a branch → ветка `main`, папка `/docs`. Ссылка будет вида `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПО/privacy-policy.html`. Для GitHub Pages репозиторий придётся сделать публичным, но ключи там не хранятся (они только в секретах).

### 4. Google Play Console
1. Создайте аккаунт разработчика (разовый взнос около 25 $).
2. Создайте приложение: Приложение, бесплатное, язык русский.
3. Заполните карточку из `store/listing_ru.md` и загрузите `store/icon-512.png` и `store/feature-graphic-1024x500.png`.
4. Добавьте не менее 2 скриншотов с телефона из реального приложения. Я их не делал, чтобы не показывать то, чего вы не видели.
5. Заполните анкеты: «Безопасность данных», рейтинг контента, целевая аудитория, ссылка на политику. Готовые ответы в `store/listing_ru.md`.
6. Release → Production (или сначала Internal testing) → загрузите `.aab`. Включите Play App Signing, когда консоль предложит.
7. Для новых личных аккаунтов Google может требовать закрытое тестирование (около 12 тестировщиков в течение 14 дней) перед публикацией. Проверьте актуальные правила в консоли.

Версия приложения 1.3.0. Идентификатор приложения `ru.familybudget.app` после первой загрузки в Play изменить нельзя. Если хотите свой, например `com.вашеимя.semeinybudget`, замените его в `app/build.gradle.kts` (`namespace` и `applicationId`) и пакет в исходниках до первой публикации.

## Что улучшено по сравнению со стартовым проектом

- Локальная база Room: данные работают офлайн.
- URL и токен вводятся в приложении, пересобирать APK ради них не нужно.
- Очередь отправки в таблицу без дублей (постоянный `uid` как `requestId`), в таблицу уходит реальная дата операции.
- Резервная копия и восстановление (JSON), экспорт в CSV.
- Подтверждение удаления, иконка (в том числе тематическая), тёмная тема.
- Готовая релизная подпись, workflow для AAB, политика конфиденциальности, материалы для магазина.

## Подключение Google-таблицы (необязательно)

Нужна таблица с листом `Операции`, колонки A:I:
дата, сумма, тип, категория, комментарий, способ оплаты, кто, счёт отправителя, счёт получателя.

1. В таблице: Расширения → Apps Script, вставьте содержимое `scripts/Code.gs`.
2. Замените `REPLACE_WITH_A_LONG_RANDOM_SECRET_AT_LEAST_32_CHARS` на случайный секрет не короче 32 символов.
3. Развёртывание → Новое развёртывание → Веб-приложение. Выполнять от своего имени, доступ: «Все» (защита идёт токеном).
4. Скопируйте URL веб-приложения.
5. В приложении: Ещё → Google Таблица. Вставьте URL и тот же токен, нажмите «Сохранить», затем «Проверить».

Названия типов в таблице: `Доход`, `Расход`, `Перевод`. Если скрипт создан не из самой таблицы, впишите её ID в `SPREADSHEET_ID`.

## Ограничения

- Изменения и удаления уже отправленных операций в таблице не обновляются, отправка идёт только в одну сторону (приложение → таблица).
- Токен хранится на устройстве в обычных настройках приложения. Не публикуйте URL, токен и APK.
- Минификация R8 выключена ради надёжности сборки: AAB получается больше, чем мог бы, но это допустимо для Google Play.
- Напоминаний о платежах (уведомлений) пока нет.
- **Код ни разу не компилировался и не запускался**: в среде автора нет Kotlin и Android SDK. Первая компиляция произойдёт в вашем GitHub Actions. Если сборка упадёт, пришлите лог ошибки. Перед отправкой в магазин обязательно пройдите на телефоне все экраны и сценарии из debug-сборки.

## Структура

```
app/src/main/java/ru/familybudget/app/
  MainActivity.kt        навигация (нижняя панель) и редактор операции
  BudgetViewModel.kt     состояние, действия, экспорт, синхронизация
  data/                  Room (операции, категории, счета, платежи), настройки, отправка в таблицу
  logic/                 расчёты (остатки, категории, месяцы, год), форматирование
  ui/                    экраны: Обзор, Операции, Отчёты, Год, Настройки; диаграммы и общие компоненты
scripts/Code.gs          Google Apps Script
.github/workflows/       облачная сборка APK
```
