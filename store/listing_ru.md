# Карточка приложения в Google Play (русский)

**Название (до 30 символов):** Семейный бюджет: план

**Краткое описание (до 80 символов):**
План трат на месяц, уровни, награды и прогноз. Без интернета.

**Полное описание:**
Семейный бюджет — учёт денег как игра: уровни, серия дней, задания и награды. Подходит тем, кто никогда не вёл бюджет: пошаговая настройка за пару минут.

📋 План на месяц: аренда, кредит, транспорт и бензин, связь, коммунальные, прочее. Каждый месяц план подставляется из прошлого.
📤 Красивый отчёт с графиками в вашу Google Таблицу, которым можно поделиться.
🔮 Прогноз: приложение считает, сколько вы потратите к концу месяца, сколько можно тратить в день и хватит ли денег.
📉 График трат по дням: факт, прогноз и линия бюджета.

📊 Месячный обзор: остаток на начало и конец месяца, доходы, расходы и разница.
💰 Обязательные платежи с галочками: отметили платёж — расход добавился сам.
🧾 Журнал операций по дням, поиск и фильтры. Расходы, доходы и переводы между счетами.
🎯 Лимиты по категориям: видно, сколько потрачено и сколько осталось.
🥧 Отчёты: диаграмма по категориям, график расходов по дням.
📈 Годовой дашборд: траты и доходы по месяцам, накопления, ТОП-15 категорий.
👨‍👩‍👧 Несколько людей и несколько счетов (карта, наличные).
💾 Резервная копия и экспорт в CSV для Excel.
🔒 Все данные хранятся только на вашем телефоне. Без регистрации и рекламы.
🌙 Тёмная тема.

Дополнительно: по желанию операции можно отправлять в вашу собственную Google Таблицу.

**Категория:** Финансы
**Контакт:** ваш e-mail
**Политика конфиденциальности:** URL страницы из docs/privacy-policy.html (см. README_RU.md, шаг «GitHub Pages»)

## Анкета «Безопасность данных» (Data safety)
- Собирает ли приложение данные пользователя: **Нет** (данные остаются на устройстве, разработчику не передаются).
- Передаёт ли данные третьим лицам: **Нет**.
- Шифрование при передаче: да (только HTTPS, и только при включённой пользователем синхронизации).
- Можно ли запросить удаление данных: данные хранятся на устройстве; удаляются удалением приложения.

## Прочие ответы в консоли
- Приложение содержит рекламу: **Нет**.
- Целевая аудитория: **18+** (финансовое приложение, не для детей).
- Рейтинг контента: насилие, азартные игры и т.п. — **нет**. Ожидаемый рейтинг: для всех.
- Тип: приложение, бесплатное.
- Разрешения: только INTERNET (необязательная синхронизация).
